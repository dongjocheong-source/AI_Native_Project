Claude API를 프로덕션 애플리케이션에 통합해야 하는 개발자를 위한 강좌입니다. 챗봇·자동화 도구·AI 기능을 만들 때 필요한 구현 패턴을 다룹니다. API 인증·기본 요청부터 프롬프트 평가, 툴 사용, MCP, RAG 파이프라인, Claude Code·Computer Use, 에이전틱 워크플로우까지 7개 모듈·67개 레슨·9시간·퀴즈 8회로 구성됩니다.

Module 01 · 2 hr

Getting Started with Claude

API 인증, 기본 요청, 대화 관리, 시스템 프롬프트, 구조화된 출력 생성까지 기초 전체를 다룹니다.

모델 개요 & 선택
Claude 모델 계열의 차이를 이해하고 유스케이스에 맞는 모델을 고릅니다.
요청 & 멀티턴 대화
첫 요청을 보내고, 멀티턴 대화로 확장해 간단한 챗봇을 만듭니다.
시스템 프롬프트 & Temperature
시스템 프롬프트로 역할을 부여하고, temperature로 출력의 창의성·일관성을 조절합니다.
스트리밍 & 구조화된 데이터
응답을 스트리밍으로 받고, 정해진 스키마의 구조화된 데이터를 안정적으로 뽑아냅니다.
Module 02 · 2 hr

Prompt Engineering & Evaluation

효과적인 프롬프트를 쓰고 테스트하는 체계적인 접근법을 배웁니다. 감(feeling)이 아니라 평가 파이프라인으로 프롬프트를 검증합니다.

Eval Workflow

평가 파이프라인

테스트 데이터셋 생성 → 평가 실행 → 모델 기반/코드 기반 채점으로 프롬프트의 강점·약점을 객관적으로 드러냅니다.

Prompting Techniques

프롬프트 엔지니어링

명확하고 직접적으로 쓰기, 구체적으로 명시하기, XML 태그로 구조화하기, 예시 제공하기 — 4가지 핵심 기법.

Try It Out

직접 실습

직접 프롬프트를 평가해보며, 기법을 적용하기 전후의 차이를 체감합니다.

Module 04 · 2 hr

Model Context Protocol (MCP)

Claude 애플리케이션에 툴·리소스를 제공하는 서버·클라이언트를 만드는 표준화된 방식을 배웁니다. 프로젝트마다 커스텀 툴 구현을 짜는 대신, 재사용 가능한 통합을 만듭니다.

서버 설정 & Inspector
프로젝트를 세팅하고 서버 인스펙터로 구현을 확인합니다.
클라이언트 구현
MCP 클라이언트를 직접 구현해 서버와 연결·통신합니다.
리소스 & 프롬프트
리소스를 정의·접근하고, 프롬프트를 정의해 클라이언트에서 활용합니다.
Module 05 · 2 hr

Retrieval Augmented Generation (RAG)

Claude의 컨텍스트 한계를 해결하기 위해, 사용자 질의에 따라 대규모 문서 컬렉션에서 관련 부분만 검색해 제공하는 RAG 시스템을 만듭니다.

Foundations

텍스트 청킹 & 임베딩

텍스트 청킹 전략과 텍스트 임베딩으로 전체 RAG 흐름의 토대를 놓습니다.

Hybrid Search

BM25 + 멀티 인덱스

BM25 어휘 검색을 결합한 멀티 인덱스 RAG 파이프라인으로 검색 정확도를 높입니다.

Advanced Retrieval

재순위화 & 맥락적 검색

검색 결과를 재순위화(reranking)하고, 맥락적 검색(Contextual Retrieval)으로 정밀도를 한층 끌어올립니다.

개발 작업에 Claude Code를 활용하고, 인터페이스 상호작용을 자동화하는 Computer Use로 애플리케이션을 만듭니다.

Claude Code 설정 & 실전

자동화된 디버깅
코드 생성·리팩터링·디버깅·문서화 작업에 Claude Code를 적용해 개발을 가속합니다.
Computer Use 원리
Computer Use가 어떻게 작동하는지 이해하고, UI 자동화 상호작용을 구현합니다.
Module 07 · 1 hr

Agentic Workflows

복잡한 다단계 작업을 처리하는 에이전틱 워크플로우를 설계·구현합니다. 언제 워크플로우를, 언제 단순 프롬프트를 쓸지부터 시작해 3가지 핵심 패턴을 다룹니다.

패턴 설명
Parallelization여러 작업을 동시에 실행해 처리 시간을 단축
Chaining한 단계의 출력이 다음 단계의 입력이 되는 순차 처리
Routing중간 결과에 따라 조건부로 분기하는 라우팅
워크플로우 vs 에이전트 — 마지막 레슨은 정해진 단계를 따르는 워크플로우와, 스스로 판단해 툴을 골라 쓰는 에이전트의 차이, 그리고 환경을 점검(environment inspection)하며 상태를 파악하는 법을 정리하며 강좌를 마무리합니다.
Conclusion
